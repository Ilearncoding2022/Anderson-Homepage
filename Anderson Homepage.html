    Project status bar

    Permission approvals

    While this page is open, permission requests from Claude Code appear as Allow / Deny buttons on the project bar instead of VS Code dialogs. Whenever the page is closed — or anything in this feature breaks — VS Code prompts as usual. Press Ctrl+Enter to allow everything waiting, as long as nothing else on the page has the keyboard. The hourglass button on each bar arms auto-allow: requests from that project that would appear here are approved automatically for the chosen 5–60 minutes. The armed pill counts down on the bar; click it to stop early. Arming survives a refresh of this page, and ends when the window expires, when the project leaves the row, when this tab closes, or when this checkbox is turned off — and the decision log records auto-approvals separately from clicks. Panic switch: tools\approve-off.cmd.
